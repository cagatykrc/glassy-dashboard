# Glassy Dashboard

Glassmorphism tarzında modern bir SaaS / admin paneli arayüzü.

React 19 + Vite + Tailwind CSS + Framer Motion ile yazılmış, demo veri üzerinden çalışan tek sayfalık etkileşimli bir dashboard UI şablonu.

## Ekranlar

- **Home** — istatistik kartları, productivity chart, takvim, aktivite, ekip
- **Projects** — kanban (In progress / Review / Done)
- **Invoices** — fatura listesi ve durum filtreleri
- **Messages** — sohbet listesi, mesajlaşma, profil paneli
- **Saved** — kaydedilen içerik grid’i
- **Settings** — profil ve tercihler
- Bildirim paneli ve Import dialog

## Teknik

- React 19, TypeScript, Vite
- Tailwind CSS 4
- Framer Motion
- Lucide icons
- Plus Jakarta Sans

Tamamen frontend; API yok, seed data kullanır.

## Kurulum

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
